# 📘 Étape 2 — Comment fonctionnent les TP

## Le principe

Toi → tu modifies un fichier dans le navigateur
GitHub → reçoit ta modification et lance un serveur Ubuntu
Ubuntu → exécute tes commandes Linux
Toi → tu vois le résultat dans l'onglet Actions

## Comment modifier un fichier

1. Ouvre le fichier dans ton repo
2. Clique sur le crayon ✏️
3. Modifie le fichier
4. Clique "Commit changes"
5. Va dans Actions pour voir le résultat

## Questions fréquentes

Est-ce que je peux me tromper ?
Oui, tu peux modifier et re-commiter autant de fois que tu veux.

Je n'ai pas d'ordinateur, je peux faire ça sur téléphone ?
Oui, GitHub fonctionne sur mobile.
