# 📘 Étape 3 — Démarrer le TP1

## 3.1 — Forker le repo TP1

1. Va sur le repo TP1 :
   **github.com/ton-pseudo/linuxsin-tp1**
2. Clique **"Fork"** en haut à droite
3. Clique **"Create fork"**
4. Tu arrives sur ta copie personnelle

## 3.2 — Par où commencer

1. Lis `consignes/tp1.md`
2. Ouvre `tp/tp1_navigation.sh`
3. Clique ✏️, complète la Q1, commit
4. Va dans **Actions** pour voir ton score
