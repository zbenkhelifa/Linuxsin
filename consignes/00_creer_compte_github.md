# 📘 Étape 1 — Créer ton compte GitHub

## 1.1 — Créer le compte

1. Va sur **[github.com](https://github.com)**
2. Clique sur **Sign up**
3. Renseigne ton email, un mot de passe, un nom d'utilisateur
4. Choisis un nom sérieux : `prenom-nom` ou `prenomnom`
5. Vérifie ton email avec le code reçu

> 💡 Ce nom sera visible par ton prof et potentiellement des recruteurs.

## 1.2 — Vérification

Tu vois ta page d'accueil GitHub avec un tableau de bord vide. ✅
